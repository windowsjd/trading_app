# 시즌 UX 3건 (2026-11-14)

랭킹 탭 최종 랭킹 자격 안내 · 정산 완료 시 시즌최종결과 자동 표시 · 시즌모드 홈 운영 기간. 서버 API·DB 변경 없음
(기존 `/ranking/qualification`, `/trading-accounts`, `/records/me/seasons/:id/final-result[/view]`).

## 1. 랭킹 탭 — 최종 랭킹 참가 기준 안내

- 위치: 내 순위 카드 → 순위 안내 → TOP3 → **안내** → 전체/친구/TOP10 탭 → 목록. 작은 빨간 글자(13, `semantic.error`),
  카드·배경·테두리 없음, 줄바꿈 허용(자르지 않음). 문구와 ⓘ가 한 버튼(44pt 대상) → 떠 있는 시트(`InlineBottomSheet`
  floating, `TriggerPriceLabel`·증거금 모드 ⓘ와 같은 패턴): 서로 다른 거래 종목·인정 거래대금마다 필요/현재 인정/추가 필요.
- 판정은 서버 것만: `features/ranking/qualification.ts`가 `state: available` + `qualified: false` + 응답 `season.id` =
  화면 시즌일 때만 안내를 만든다. 서버 필드끼리 모순(충족 표시와 잔여량 불일치 등)·누락·읽기 실패는 아무것도 보이지 않는다.
  미참가(요청 안 함)·참가 제외·기준 없는 시즌도 표시 안 함. 금액: 필요·추가 필요는 원 단위 올림, 현재는 내림.
- 문구: 진행 중 `최종 랭킹 참가 기준을 아직 충족하지 못했습니다.`, 종료~정산 전 `… 충족하지 못했습니다. 정산 후 확정됩니다.`,
  정산 후 `… 충족하지 못해 최종 순위에 포함되지 않았습니다.` 정산 시즌 미달자 내 순위 카드 = `최종 랭킹 자격 미충족`,
  적격자 0명 시즌 = `최종 랭킹 참가 기준을 충족한 참가자가 없습니다.`
- 갱신: 키 `['ranking','qualification',seasonId]`(시즌 체결 후 `ranking.all` 무효화로 재조회), 탭이 보이고 진행 중 미달일 때
  60초마다. 거래 차단 아님.

## 2. 정산 완료 → 시즌최종결과 자동 표시 (`features/season/SeasonResultAutoOpen.tsx`)

- 원인: 계정 목록은 시즌 계정이 `active`일 때만 30초 폴링 → 종료 tick에 `ended`가 되면 폴링이 멈춰 `ended → settled`를
  재로그인 전까지 보지 못했다. 홈에는 결과 화면으로 가는 자동 경로가 없었다(버튼만).
- MainTabs의 진입 overlay 슬롯 안(업데이트 안내·공지 팝업 옆), **선택된 시즌 계정만**: `ended`이면 앱이 앞에 있을 때 30초마다
  목록 재조회(배경에서는 안 함, 복귀 즉시 1회) → `settled` + `finalResultViewedAt === null`(명시적 null; 필드 없는 구 서버 =
  모름) → 결과 GET → 같은 시즌·`settled`·`viewedAt null`·화면이 보여 주는 상태(available/not_qualified/excluded)일 때만
  → 홈 첫 화면에서, 가이드 없음, 슬롯을 얻은 뒤 350ms 후 `SeasonFinalResult`로 한 번 이동(실행 중 회원·계정·시즌당 1회).
  결과 화면이 떠 있는 동안 슬롯을 유지해 업데이트 안내·공지 팝업과 겹치지 않는다. 확인 기록은 기존대로 결과 화면이 표시 후 POST.
- 계정 전환·로그아웃·일반/초보 모드는 대기 중 이동을 취소한다. 결과 GET 실패는 아무것도 열지 않고, 앞으로 돌아올 때와
  60초 간격(최대 5회)으로 다시 읽는다. 새 시즌 계정을 쓰는 중에는 지난 시즌 미확인 결과를 덮어 띄우지 않는다(계정 선택의
  `시즌결과 확인하기`, 그 계정 홈의 `시즌최종결과 보기`로 확인).

## 3. 시즌모드 홈 상단 운영 기간 (`features/season/seasonPeriod.ts`, `AccountSwitcher` homeHeader)

- `season0 [beta]` 아래 `2026.11.14 ~ 2026.11.29`(12/16, `semantic.secondary`), 계정변경 칩은 그대로 옆. 한 44dp 버튼.
- 날짜 = 선택 계정 시즌의 `startAt` KST 날짜 ~ (`endAt − 1ms`) KST 날짜(`endAt`은 배타적 경계). 고정 KST 포맷터
  (`formatKstDateTime`), 기기 시간대 무관. 값이 없거나 잘못되면 표시하지 않음. 일반·초보 모드에는 없음.
- 네이티브 헤더 높이 안: iOS 44pt·Android 56dp에 두 줄(이름 24 + 기간 16)이 들어가도록 글꼴 배율 상한(iOS 1.1, Android
  1.4)을 `homeSeasonHeaderLayout`이 계산하고, 기간 줄이 계정변경 옆에서 줄바꿈되지 않도록 폭으로도 제한한다. `beta` 알약
  글자도 같은 상한을 따른다(`SeasonTitle`의 `maxFontSizeMultiplier` — RN-Web 점검에서 iOS 2배일 때 알약이 첫 줄을 키워 기간
  줄이 막대 밖으로 나가던 것을 발견해 고침).
