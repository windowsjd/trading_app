# 가이드 화면 정리와 체결괴리 방지시스템 공지 (2026-10-12)

시작 `main` = `origin/main` = 원격 main `9570c499`, clean. frontend만 변경. 거래·체결·호가 수집·서버 API는 변경하지 않았다.

## 변경과 의도

1. **가이드 메인 상단** — 소개 문구와 '기초 가이드' 제목 삭제(헤더가 이미 '가이드'). 목록은 콘텐츠 패딩(16)에서 바로 시작한다.
   초보 계정 퀘스트 탭의 '가이드' 구간도 같은 `GuideScreen`이라 함께 바뀐다.
2. **'이용 가능' 삭제·'학습 시작' 버튼·숫자** — 메인/상세(시장기초, 주식특성 등) 카드를 `LessonUi`의 `GuideCard` 하나로 통일.
   번호 26/800 tabular(보조 행동 전경색, 라이트 #285B85·다크 #70AFFF)를 제목(20/700)과 같은 baseline에 두고, 큰 글꼴에서는
   제목이 아래로 줄바꿈된다. '학습 시작'은 앱의 보조 행동 표면(홈 '자세히 보기'와 같은 `secondaryActionSurface`, 높이 ≥44)으로
   만든 버튼이다. **카드 전체가 하나의 터치 대상**이고 버튼은 그 시각적 행동이다: 버튼 안의 버튼(웹 `button` 중첩·스크린리더
   중복 초점)을 만들지 않고 기존 이동·testID를 유지하기 위해서다. 접근성 이름은 '번호 제목. 설명. 학습 시작', hint는 유지/추가.
   목록 6개 카드마다 그라데이션을 쓰면 화면의 주요 행동이 6개가 되어 보조 표면을 택했다.
3. **가이드 화면 제목 굵기** — `GuideStack`의 header title에 테마 `fonts.heavy`(700) 적용. 탭 루트 헤더(MainTabHeaderTitle)와
   같은 굵기이며 iOS 기본 600·Android medium보다 굵다. 크기·헤더 높이·뒤로가기 배치는 플랫폼 기본 그대로.
4. **공지사항** — 공지 API·데이터가 없어(빈 상태 화면뿐) 앱에 포함된 정적 목록 `features/notice/notices.ts`를 만들었다.
   전체 > 공지사항은 항목을 제자리에서 펼치는 목록이다. `Notices` 라우트의 선택적 `noticeId`가 그 공지를 펼치고 그 위치로
   스크롤한다(별도 상세 라우트를 두면 다른 탭에서 진입할 때 스택이 [전체, 상세]가 되어 뒤로가기가 목록을 건너뛴다).
   공지 내용은 실제 정책 범위만 말한다: 주문은 거래소로 가지 않음, 체결 시점 최신 실제 시세 재확인, 오래되거나 없는 시세는
   체결하지 않음, 현물 견적-체결 가격 변동 허용 범위. 운영에 비활성인 호가 깊이 평가(ERS)는 주장하지 않는다.
5. **호가창과 체결 문구·링크** — '호가창은 현재 거래소에…' 삭제, '모의투자에서 발생하는 거래는 실제 호가창에 적용되지 않습니다.
   대신 체결괴리 방지시스템이 적용됩니다.'로 교체. 용어는 밑줄·굵게·보조 행동 전경색이고, 문장 줄 전체(높이 ≥44)가 하나의
   `link` 역할 터치 대상이다(작은 인라인 글자만 누르는 것보다 터치·스크린리더가 안정적). 누르면
   `MainTabs > MyTab > Notices { noticeId, initial: false }`로 이동해 공지가 펼쳐진 채 열린다. 헤더 뒤로가기 → 전체,
   가이드 탭으로 돌아가면 보던 학습이 그대로 있다. 가이드 모듈의 서비스 격리 규칙 때문에 공지 id는 `constants/noticeIds.ts`에 둔다.
6. **매수 실행 버튼 그라데이션** — 기존 `ActionPressable primary`(primaryGradient #326FE5→#4C32E5, 흰 글씨, 기존 누름 피드백)
   재사용. 대상과 정책 변경은 `pressed-feedback.md` 2026-10-12 절. 실제 주문 화면 버튼은 공유 컴포넌트가 아니라 영향 없음.
